# octocov-central

Central [octocov](https://github.com/k1LoW/octocov) coverage badges and dashboard for
[@ivanklee86](https://github.com/ivanklee86)'s projects — publicly embeddable badges and durable
coverage history, collected on a schedule from each source repo's `artifact://` datastore.

This README is regenerated by [`.github/workflows/central.yaml`](.github/workflows/central.yaml)
(octocov's ["central mode"](https://github.com/k1LoW/octocov#central-mode)) — don't hand-edit it
once that workflow has run successfully; edit `.octocov.yml` instead.
